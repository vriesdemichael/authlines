Why does my access token say that?

Open it, and see which setting put each thing there.

What it carries

  • access_token body What the app shows an API to be let in.
  • token_type=Bearer body Says how to use the token: whether holding it is enough, or it takes a proof too.
  • id_token body Here its sid and auth_time match the first app, and its aud is this app From: OpenID Connect, Log in to a second app
  • expires_in body How many seconds the access token lasts.
  • refresh_token body Gets a new access token later, without the user having to log in again.
  • scope body What the access covers, which is not always what was asked for.
