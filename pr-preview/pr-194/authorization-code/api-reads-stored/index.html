What if this API is not allowed it?

The identity provider refuses. On the server recorded, a not allowed this provider got a 403 with and: Client not allowed to retrieve token for the provider. A token that did not name the API got a 403 with and: Client is not within the token . And the app with no secret, asking itself, got a 403 and: not allowed.

In Keycloak: Allow retrieve external tokens, for the API

On the API’s own client here, with this provider named in Allowed Identity Providers for External Tokens. A client allowed only another provider, or with the setting off, got a 403 with invalid_client and: Client not allowed to retrieve token for the provider. The console only shows it on a server with API V2 on.
