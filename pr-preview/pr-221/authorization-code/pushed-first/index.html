Which spec says so?

In Keycloak: Require PKCE

Off by default, so a login with no challenge goes through. Turn it on, and the app gets an error back at its redirect URI instead of a code.

Clients › your client › Settings › Capability config › Require PKCE

Changed this, and the answer changed, on Keycloak 26.8.1.

In Keycloak: Pushed authorization request required

Off on a new client, so it takes an ordinary login link as well as a pushed one, and someone else can still start a login for it with a link of their own. On, a link that was not pushed sends the browser back to the app with error=invalid_request and: Pushed Authorization Request is only allowed. For an app with no secret that stops less, because anyone can push a request for it.

Clients › your client › Advanced › Advanced settings › Pushed authorization request required
