Why does this one site ask for my password?

It can be because the browser was not told it may send a ticket there. Chromium sends one only to a site on its list, or on Windows, with no list set, to sites Windows counts as the local intranet. The one recorded here was given no list, and the one that sent a ticket was given one. Off its list, Chromium’s page says, a browser asks for a username and password, and on Windows it can, in a dialog of its own, which the user cancels to reach the login page. The Chromium recorded, on Linux, did not ask. A good ticket can still end at the login page, when the identity provider cannot find who it names. Other reasons a ticket does not get someone in, which were not recorded: a computer with no ticket at all, because the user did not log in to the network, a clock too far from the others, or a host name, the real one behind any alias, that is not the one the identity provider’s principal names.
