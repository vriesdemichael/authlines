In Keycloak: What a real server did after a logout

The access token still had most of its life, and an API that only looks at the token took it. UserInfo said 401, and a refresh said Session not active, for the other app too, and the other app's next login showed the form.

Tried each of these with two clients, on Keycloak 26.8.2.

In Keycloak: SSO Session Idle and SSO Session Max

Thirty minutes idle and ten hours at most, by default, and a refresh token ends with the session: it came with thirty minutes left. Made five seconds, either one had a refresh token refused seven seconds later, with Token is not active, and idle at five seconds, one used every three kept working for nine: using it keeps it going. Signing the user out from their page in the console ended it too. None of these ended an offline token.

Realm settings › Sessions › SSO Session Idle

In Keycloak: Offline Session Idle and Offline Session Max

Thirty days idle by default, which is the time an offline token came with, and no maximum, because Offline Session Max Limited is off. Turned on, Offline Session Max is sixty days.
